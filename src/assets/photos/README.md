# Photography

All four images in this folder are **Unsplash placeholders** for the demo. Swap each with a real Corner Company photo before final handoff.

| File | What it should show | Used in |
| --- | --- | --- |
| `hero-pastry.jpg` | Strongest food shot (e.g. pastry with citrus garnish on a tray) | Home Hero |
| `exterior.jpg` | The brick storefront on E Main St | VisitSection |
| `pastry-tray.jpg` | Warm pastries on a stainless tray | MenuPreview aside, `/menu` Breakfast aside |
| `drip-chalkboard.jpg` | The drip-coffee chalkboard or atmospheric pour | MenuPreview aside, `/menu` Coffee & Tea aside |

To swap, replace the file at the same path with the same filename and rebuild. The `<Image>` component handles the rest (WebP, responsive sizes, lazy loading).
